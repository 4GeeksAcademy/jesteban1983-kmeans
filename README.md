# California Housing: K-Means and supervised classification

This project applies unsupervised and supervised learning to the California Housing dataset. It groups homes using latitude, longitude, and median income (`MedInc`), then trains a classifier to reproduce the labels generated by K-Means.

## Implemented workflow

1. Load and validate `data/housing.csv`.
2. Reproducibly split the data into training (80%) and test (20%).
3. Standardize `Latitude`, `Longitude`, and `MedInc`.
4. Train K-Means with 6 clusters, `random_state=42`, and `n_init=20`.
5. Predict clusters for train and test.
6. Train a `RandomForestClassifier` using the K-Means labels from train.
7. Save metrics, labeled datasets, a plot, and both serialized models.

## Structure

```text
├── data/housing.csv
├── data/processed/ (labeled CSVs, metrics.json, clusters.png)
├── models/ (kmeans_pipeline.joblib, cluster_classifier.joblib)
├── src/app.py
└── requirements.txt
```

## Installation and execution

Python 3.11 or newer is recommended:

```bash
pip install -r requirements.txt
python src/app.py
```

An alternative CSV can be provided with `python src/app.py --data path/to/housing.csv`. The command prints the metrics and refreshes artifacts in `models/` and `data/processed/`.

## Results

With `random_state=42`, the pipeline processes 20,640 rows (16,512 train and 4,128 test), obtains a train silhouette score of approximately **0.394**, and reaches approximately **0.995** accuracy when the supervised model reproduces K-Means test labels. This accuracy measures agreement with automatically generated labels, not independently labeled ground truth.

`data/processed/clusters.png` plots longitude and latitude, colors points by K-Means cluster, and marks test points with an `x`. The clusters are driven mainly by geographic position, with `MedInc` adding information.

## Saved models

- `models/kmeans_pipeline.joblib`: `StandardScaler` + `KMeans` pipeline.
- `models/cluster_classifier.joblib`: supervised Random Forest.

```python
import joblib

kmeans = joblib.load("models/kmeans_pipeline.joblib")
classifier = joblib.load("models/cluster_classifier.joblib")
new_points = [[34.05, -118.25, 4.5]]  # Latitude, Longitude, MedInc
print(kmeans.predict(new_points))
print(classifier.predict(new_points))
```

## Reproducibility

The pipeline uses fixed seeds and stores its configuration and metrics in `data/processed/metrics.json`.
